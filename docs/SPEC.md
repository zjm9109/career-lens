# career-lens 项目说明书（v0.2）

> 求职者侧浏览器扩展：在 Boss 粗筛结果上做本地精筛，导出 Markdown 结果。  
> 第一版平台：Boss 直聘；架构预留猎聘 / 智联。

---

## 1. 产品定位

| 项 | 说明 |
|----|------|
| 名称 | career-lens |
| 用户 | 求职者 |
| 一句话 | Boss 粗筛之后，按个人画像本地精筛，输出匹配度与链接文档 |
| 形态 | Chrome / Edge 扩展（Manifest V3），无自建后端 |
| 模型 | 用户自备 Key；单选 DeepSeek / 通义千问 / 腾讯混元 / OpenAI / Gemini |
| 运维 | 日常无需作者值守；Boss 改版时更新扩展 |
| 不做 | 自动投递、自动打招呼、绕过验证码、未授权批量 API |

---

## 2. 与 Boss 分工

**Boss 负责（不进扩展表单）：** 城市、全职/兼职、薪资、经验、学历、行业、公司规模。

**扩展负责：** 顺序读岗 → 避雷 / 注意 / 加分 → 条件满足时 DeepSeek 分析 → 导出 MD；可选自动收藏。

---

## 3. 核心流程

### 3.1 列表精筛

1. 用户登录 Boss 并手动筛选列表  
2. 扩展按需缓慢下拉补列表  
3. 对每条：方向词（默认不拦截）→ 进详情 → 避雷 → 注意 → 加分打分 →（未排除且规则分≥阈值）DeepSeek → 写结果 →（未排除且≥收藏阈值）自动收藏（已收藏不取消）  
4. 批次规则触发后下载 / 休息 / 停止  

### 3.2 精确分析

文本框粘贴 JD，走同一套逻辑，来源标记「手动粘贴」。

### 3.3 画像录入

手填，或 PDF / Word 上传解析预填后修改；存 `chrome.storage.local`。  
PDF 使用扩展内 **pdf.js** 提取（支持中文 ToUnicode）。  
**加分权重**与技能/行业/方向/证书/语言标签并列展示在画像页，保存时归一。

---

## 4. 标签与计分

### 4.1 三套标签

| 名称 | 计分 | 行为 |
|------|------|------|
| 避雷项 | 否 | 命中则排除；列出命中项；仍算规则分；不调 DeepSeek |
| 注意项 | 否 | 仅结果提醒；与避雷共用词库 + 自定义，行为不同 |
| 加分项 | 是 | 唯一规则分来源 |

### 4.2 避雷默认词

词库：加班、出差、驻场、外包、派遣、客服、销售、运维、培训、异地、倒班、夜班、值班、咨询、电推、应酬、驾照；支持自定义。宽匹配（包含即命中）。  
**默认不勾选**，由用户按需选择。

### 4.2b 硬门槛与建议分组

- **硬门槛缺口**：从任职要求语义抽取（如 N 年以上、必须持有 PMP）；与画像年限/证书对比，缺失则列出（「优先」不计硬门槛）。
- **结果分组**：建议投递 / 谨慎 / 排除（导出与侧栏）。排除=避雷；谨慎=模型建议谨慎/不建议、或有硬缺口、或规则分低于 60；其余达标为建议投递。
- **投递列表**：达标（默认≥收藏阈值）写入列表，最多 100 条；支持打开链接（非自动投递）、多选、分页 30。
- **断点续跑**：暂停/验证码/停止会保存进度，「续跑」从下一条继续；开跑前做 DOM 健康检查。

### 4.3 加分默认权重（可调，归一化到 100）

| 维度 | 权重 |
|------|------|
| 技能 | 40 |
| 行业 | 20 |
| 方向词 | 15 |
| 证书 | 15 |
| 语言 | 10 |

### 4.4 计分算法（v0.2）

- 技能：优先 Boss「职位关键词」标签，正文补充；覆盖率后 **sqrt 软化**：`round(sqrt(hit/R)*100)`；抽不出要求 → 100  
- 行业：命中任一用户行业 → 100，否则 0；看不出 → 100  
- 方向词：标题命中 → 100；仅正文 → 70；都无 → 0；未填 → 100  
- 证书 / 语言：无要求 → 100；有则按命中比例或满足/不满足  
- 关联词（熟悉/精通/优先等）：第一版简单处理，联调再细化  

### 4.5 阈值

| 项 | 默认 | 范围 |
|----|------|------|
| DeepSeek | 60 | 0–100；仅未排除且规则分≥阈值；只做分析不算分 |
| 自动收藏 | 80 | 0–100；仅未排除；已收藏不取消；结果 MD 按分数降序、同分按处理顺序 |

DeepSeek 输出：一句话结论、岗位成分识别、亮点、缺口、是否建议投递、改简历侧重点。

---

## 5. 批次与风控

| 规则 | 值 |
|------|-----|
| 下拉 | 按需缓慢 |
| 批量 | 10–100，默认 10 |
| ≥50 | 每 30 条休息 30 秒 |
| 100 | 硬停 |
| 验证码 / 页不可见 | 暂停，手动继续 |
| 间隔 | 浅层 2–5s；完整分析 3–10s 随机 |

结果文件：时间戳新文件名；边写边累积，导出时按 **分数降序、同分按处理顺序**。

---

## 6. 导出

- **格式：** Markdown（`.md`）或 Word（`.docx`）  
- **精简（默认）：** 岗位名、公司、链接、匹配度、职位标签、避雷/注意、分析（无可读数字则不写薪资）  
- **详细：** 另含工作职责 / 任职要求 / 加分项分块与分项得分

## 7. 工程结构

```

  common/           # 存储、打分、导出、DeepSeek、简历解析
  platforms/boss/   # 列表/详情/收藏/下拉

  background.js
  manifest.json

```

平台：`platforms/boss`、`platforms/liepin`、`platforms/zhilian`（按当前标签页 URL 自动识别，无需单选）。

## 8. 验收（第一版）

1. Boss 列表可顺序精筛并导出 MD  
2. 避雷 / 注意 / 加分与阈值生效  
3. 自动收藏不取消已收藏  
4. 粘贴 JD 可精确分析  
5. 批次、休息、可见性暂停可用  
6. 无自动投递、无后端依赖
