# career-lens 变更记录

## 2026-08（v0.3 强化：语义四维 · 猎聘稳态 · 需求覆盖）

相对 v0.3 初版，本轮在「能跑通」之上补齐匹配可信度与三平台可用性。

### 已增加

#### 1. 契合四维 + 语义/向量（替代旧五维主路径）

| 维度 | 默认权重 | 含义 |
|------|----------|------|
| 角色契合 | 25 | 岗位角色是否同类 |
| 领域契合 | 30 | 行业/业务场景是否同域 |
| 能力契合 | 30 | 方法、工具、技能覆盖 |
| 资质条件 | 15 | 证书/年限/语言等（硬项仍先走门禁） |

- 有 API Key：OpenAI / 通义优先 **embedding 余弦**；DeepSeek 等走 **LLM JSON 四维**  
- 无 Key：规则映射 + 职业包域词仅作兜底  
- 职业包（`packs/*.js`）降级为：**适合岗位展示 + 无 Key 域兜底**，不再「一个岗位一个大 JSON」  
- 旧五维权重自动迁移到四维  

#### 2. 需求覆盖更贴近真实 JD

- **或选句**：`精通 ERP、OA、CRM 等至少一种` / `熟悉 Java 或 Python` → 一个需求单元，命中任一即满足  
- **匹配度**：按需求单元覆盖率（已满足 / 全部单元），不是字面词全中  
- **PM 过程隐含**：有项目经理 / PMP / 项目管理背景时，评审会、资料归档、交付复盘、会议纪要等视为已覆盖  
- **福利标签**：五险一金、年终奖等不再当必备能力缺口  
- **JD 具体度**：空泛套话岗降分封顶，防虚高  

#### 3. 猎聘可用性

- 识别分页（约 15–20 条/页），本页结束可 **CL_NEXT_PAGE** 翻页  
- 放慢开详情节奏（约 8–14s/条、每 8 条休息），降低「账号行为异常」  
- 详情进 `safe.liepin.com` / 短信验证 → **立即暂停**  
- 修正详情采集：须等到「职位介绍」就绪；避免顶栏壳、猜你喜欢串台（公司/薪资）  

#### 4. 本地存储

- 断点重复写入完整 JD 易触发 `Resource::kQuotaBytes quota exceeded`  
- 已加 `unlimitedStorage`，并对 runState / listSession / 投递列表 **压缩存盘**（去重、截断长文）  
- 仍满：侧栏「从头」或扩展管理页清除本扩展数据  

#### 5. 其它已有能力（v0.3 基线，本轮文档对齐）

- 硬门槛门禁（证书/语言/年限；UNKNOWN→FAIL）+ 封顶分  
- 待复核（防漏）：高契合被压分仍可 AI、可进投递列表  
- 规则侧写 + 可选 AI 侧写；投递列表导出 CSV

### 后续优化方向

| 优先级 | 方向 | 说明 |
|--------|------|------|
| 高 | 评测集固化 | 热力建造师、压裂英语、AI 漫剧、汽车悬架 PM、空岗套话等固定样例，防回归 |
| 高 | 猎聘稳态再收敛 | 可配置条间隔；风控后一键续跑提示；列表指纹与翻页游标更稳 |
| 高 | 语义成本与缓存 | 同 JD 向量/四维结果短期缓存；批量时少重复调模型 |
| 中 | 本地 embedding | 可选小模型/本地向量，降低对云端 Key 依赖 |
| 中 | 断言证据链 UI | 侧栏逐条对照 JD 句 ↔ 简历证据 |
| 中 | 稀疏 JD / 中性维 | 继续收紧「无要求→中性高分」 |
| 中 | UNKNOWN 策略设置 | 严/松可配（当前固定严） |
| 低 | 更多职业包展示 | 工程现场、销售等：仍以展示+无 Key 兜底为主，不堆大 JSON |
| 低 | 侧写版本号 | 「基于旧侧写」标记，避免画像与侧写漂移 |
| 低 | 职业包外置 | 可订阅/用户自建包（非写死仓库） |

原则不变：**门禁看硬事实；契合看语义覆盖；职业包不膨胀成主引擎。**
